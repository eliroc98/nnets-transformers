**Fresh reference definitions**

`random-token-induction-v1` generates seeded distinct non-special tokenizer tokens, using `BOS A A[:-1]` as the prompt and the withheld last token of A as its clean answer. `induction-repeat-target-logprob-v1` scores the last valid prompt position using FP32 full-vocabulary log-softmax, in nats. This development probe is independent of the historical passage and fixed vocabulary index. Immutable tokenizer revisions stay fixed when selecting different model checkpoints; sample/candidate/position/mask manifests are saved in `dataset.json`.

The adapter inventory `tl-existing-sites-v2` records embedding and existing q/k/v/rotary-q/rotary-k/z/post-MLP hooks, optional attention-head indices and owned tensor axes. Loaded Pythia weights use explicitly recorded unprocessed normalization/writing/unembedding conventions. Query and key/value counts are recorded separately; grouped-query architectures are rejected until validated. Whole-component cosine averages feature-axis cosine over valid positions and eligible heads; individual-head observations select that head before the same reduction. `masked-cosine-relative-l2-v1` also records relative Frobenius change over valid entries and zero-norm fractions. Relative L2 is null with an explicit status for clean norm <=1e-12; cosine retains PyTorch's epsilon convention. Behavioral effects and activation changes stay separate.

`fresh-reference-v1` commits one atomic checksummed JSON shard per example/intervention. A manifest owns the expected shard plan and source/config/model/dataset identities. Resume validates these before reuse; writer locking prevents concurrent scientific writes. Each attempt preserves readable/structured logs and reports skipped versus completed work. Aggregated CSVs average per-example cosine first, then graph analysis applies its declared threshold. Per-example JSON observations remain available for later uncertainty analysis.

CPU analysis verifies completed fresh manifests and source/input/output hashes, uses the full adapter inventory, and carries scoring/dataset identity into exports. Graph metadata records `measured_admissible_pairs`, `measurement_coverage` and `measurement_status`. Unmeasured pairs are not threshold-rejected observations; metrics derived from a smoke subset are labeled partial. No display cap or filter changes full selected-graph calculations.
